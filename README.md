# FantasyHost

FantasyHost 是用 C++ 和 Qt 6 Widgets 开发的桌面数据流工具。把设备输入、数据处理和结果展示模块放到画布上，再通过端口连成一条可运行的数据流。

## 操作

1. 从空白画布开始。双击模块库条目，或在画布空白处右键添加模块。滚轮缩放，中键或 `空格` 加左键拖动画布，`Home` 适配画布。
2. 将输出端口拖到输入端口接线。一个输出可连多路，每个输入接一路。拖入新的兼容连接会替换旧连接。选中连线或模块后按 `Delete` 删除。
3. 选中串口模块，配置串口后点击 **打开串口**。示波器收到输入即显示波形，可在自己的参数面板暂停或恢复。接线和布局可随时编辑。修改串口硬件配置时，先关闭该串口。
4. 拖动示波器、波形记录器或频谱分析仪卡片的右下角调整大小。用 `Ctrl+S`（macOS 为 `⌘S`）保存 `.fhgraph` 工程，记录卡片位置、尺寸、参数和连线。
5. 在 **视图 → 外观** 选择跟随系统、浅色或深色。画布默认使用软件绘制，也可在 **视图 → 画布使用 OpenGL** 切换后端。

## 模块

**串口收发**有一个发送输入和一个接收输出。可设置串口、波特率、数据位、校验、停止位和流控。打开此模块的串口后，可输入 UTF-8 文本或 `01 A0 FF` 格式的 HEX 手动发送，并按需追加 LF、CRLF 或 CR。接收预览可在文本与 HEX 之间切换。连线始终传递原始字节，发送追加选项仅作用于手动发送。

**示波器**支持 1–8 个通道。单路采集时，把串口的接收端连到示波器的 CH1。设备每次发送一组多路样本时，选择 **单线多通道帧**，并将接收端连到 **多通道帧** 端口。若通道由不同来源提供，则选 **逐通道接线**，分别连接对应端口。缩减通道、或将逐通道切为单线时，系统会移除消失端口上的连线。

- **文本样本**以 LF 或 CRLF 结束一行，小数点使用 `.`。逐通道时每行一个数值。单线多通道时每行依次发送各路的值，例如两路可以发送 `1.25,-0.8\r\n`。数值可用逗号、分号或空白分隔。
- **二进制样本**可选 UInt8、Int16 LE、UInt16 LE 或 Float32 LE。单线多通道模式按 CH1 到 CHn 交错接收，字节流从完整帧的开头开始。
- **显示与触发**可设置采样率、时基、垂直刻度、垂直偏移，以及触发模式、通道、边沿和电平，并支持暂停与重新触发。采样率应与设备的每通道采样率一致。每通道缓存最多 16,384 个样本，波形下方显示有效时基。

**文本显示**支持多行模板。在参数面板输入 `温度 {temperature} °C，状态 {status}` 并点击 **应用模板**，卡片会生成 `temperature` 和 `status` 两个输入端口。同一个名字出现多次时只生成一个端口，所有对应位置显示该端口最近收到的值。可连接数值或 UTF-8 字节流。未收到数据时显示原占位符，双写大括号 `{{` 或 `}}` 可显示字面大括号。应用模板后，原名保留的输入端口继续使用现有连线，删除占位符会移除对应连线。无占位符的模板可用作静态文本。

**波形记录器**使用与示波器相同的输入格式和通道配置，将收到的所有有效样本追加到磁盘暂存。各通道从零计时，按参数面板中的采样率生成时间轴。记录可在本次工程会话内回看，工程文件保存模块配置，持久保存样本请导出 CSV。

| 鼠标在记录器上的位置 | 操作 |
| --- | --- |
| 时间轴、纵轴 | 滚轮缩放所在轴，`Shift` + 滚轮或左键拖动平移所在轴 |
| 波形绘图区 | 悬停在附近波形上显示十字线、通道、时间和值 |
| 轴区之外 | 滚轮缩放画布 |

两个轴均可缩小到显示全部数据，也可以点击 **显示全部数据** 同时复位。分离显示时，各通道继续共享两轴范围。**导出 CSV** 保存导出时已记录的所有样本，按通道列出 `time_s,channel,value`。**导出当前视图** 保存当前时间和纵轴范围的 300 DPI PNG。

在记录器参数面板选择 **视口输出**。选 **合并多通道** 时，**视口波形** 端口一次传输全部通道。选 **逐通道输出** 时，每个 CH 端口只传对应通道。**合并与逐通道** 同时提供两种接线。数据包含当前时间窗内的原始采样和两轴范围。

**频谱分析仪**的 **输入布局** 可选 **合并多通道** 或 **逐通道接线**。合并模式接到 **波形** 输入，逐通道模式可配置 1–8 个独立输入，并允许从不同记录器接线。**显示通道** 设为 0 时叠加所有可用频谱，设为通道号时只显示指定通道。图例显示各通道的峰值频率。

分析参数包括 FFT 点数、窗函数、线性或 dB 幅值、去除直流和频率上限。频率上限设为 0 时，每路分析到自身采样率的一半。各路使用时间窗内最新的等间隔采样。固定 FFT 点数时，样本不足会补零，超过点数时取最新样本。dB 幅值的参考值为 1。

## 构建

需要 CMake 3.21 或更高版本、C++17 编译器和与编译器匹配的 Qt 6.5 或更高版本。安装 Qt Widgets 和 Qt Serial Port。以下命令使用 Ninja。Windows 上用 MinGW 时，将 Qt 配套的 MinGW `bin` 目录加入当前构建终端的 `PATH`。

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="<Qt 套件目录>"
cmake --build build --config Release
cmake --install build --config Release --prefix "<项目绝对路径>/out"
```

Windows 安装输出的入口为 `out/bin/FantasyHost.exe`，带 Qt 运行依赖。macOS 安装输出为 `out/FantasyHost.app`。Linux 端由发行版或打包工具提供对应的 Qt 运行依赖。

安装 Qt OpenGL Widgets 后可构建 OpenGL 画布选项。用 `-DFANTASYHOST_OPENGL=OFF` 可构建只含软件绘制的版本。

## 源码结构

- `graph` 管理节点、端口连接约束和工程格式。
- `modules` 定义端口与参数并注册模块实现。新增模块时在这里添加定义和工厂，界面会根据定义展示端口和参数。
- `runner` 管理模块的独立状态、参数同步和数据传递。
- `scope` 管理各通道的采样缓存、显示时间窗和触发。
- `waveform` 管理波形历史、视口快照和导出，`spectrum` 对视口样本执行 FFT。
- `canvas` 和 `window` 分别实现画布交互与桌面窗口。
- `theme` 维护窗口和画布共用的深浅配色。
